ShirleyOS Simple Stack Report

ShirleyOS 系統簡明架構與能力報告

以最直觀的「5 層階梯架構」呈現 ShirleyOS 的軟體堆疊，並展示原生 Rust 高階驅動與子系統的實作整合。

層次堆疊模型 (System Architecture Stack)

Layer 5 · Ring 3 / EL0
使用者空間
開機直達 PID 1 Shell (/bin/init)，具備終端互動、行編輯、指令直譯與 ELF 應用程式執行能力。
/bin/init /bin/hello Minimal Libc 17 Syscalls
Layer 4 · Subsystems
高階驅動與儲存
現代檔案系統與高階安全驅動。負責檔案路徑、磁區快取解析與對外資料處理。支援由 Rust 語言實作高階驅動！
Rust Drivers VFS & devfs exFAT 讀寫 ext4 唯讀 VirtIO-Block
Layer 3 · Kernel Core
通用核心服務
跨架構中立的核心中樞。負責全域裝置註冊表、記憶體堆積管理 (Heap/Page)、主控台串流與中斷派發邏輯。
Device Registry 1MB BSS Heap Page Allocator shirley::irq
Layer 2 · Hardware Abstraction
CPU 架構與平台
CPU 架構 (arch/) 與 硬體平台 (platform/) 嚴格分離。負責特權級別切換、分頁表映射與晶片組中斷控制器。
x86_64 (GDT/IDT) ARM64 (EL1) 8259A / GICv2 Apple Silicon (AIC)
Layer 1 · Early Stage
韌體與開機交接
UEFI PE32+ 與 BIOS 開機載入器，將各平台差異歸一化為統一的 BootInfo 契約後移交控制權。
UEFI (BOOTX64/AA64) BIOS Boot Sector FDT Device Tree BootInfo ABI

💡 核心設計特點

  • 架構與平台解耦：Apple Silicon 是 ARM64 的一個平台，而非獨立 CPU 架構。
  • 唯一命名抽象：路徑是核心中唯一的物件名稱，cat /etc/motd 與 cat /dev/kbd0 走相同 VFS 路徑。
  • 低功耗待機：閒置時執行 hlt / wfi，無輪詢，全字元由中斷驅動。
  • 開機即用：唯讀根檔案系統 (SHRFS1) 打包進核心，無磁碟驅動亦可運行。

🦀 Rust 在架構中的定位

  • 置於第 4 層（高階層）：不碰底層 GDT/IDT 特權碼，專門負責複雜協定與外設驅動。
  • 共用核心堆積：透過 #[global_allocator] 直接接入 ShirleyOS 核心堆積，享有 Vec、String 等動態能力。
  • 防止記憶體漏洞：解析外部磁碟與裝置數據時，杜絕緩衝區溢位與釋放後使用 (UAF)。
  • 首個驅動落地：/dev/rust0 已成功在 x86_64 與 ARM64 雙平台開機註冊並運作。
